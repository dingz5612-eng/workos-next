# 经营总架构

## 七层总架构

```text
来源归因层
-> 共享治理层
-> 业务域事实层
-> 财务真值层
-> 执行层
-> 读模型与分析层
-> 体验层
```

七层不是组织部门，也不是页面导航。它们定义事实归属、读写边界和执行路径。三语言合同横向作用于体验层、执行层和所有读模型展示，不改变事实归属。

## 1. 来源归因层

职责：

- 记录需求、申请、线索、推荐、活动、触点和内部请求从哪里来。
- 保存原始诉求、接入时间、接入人、候选业务域和初始证据。
- 输出 `SourceAttribution`，支持后续转化分析，但自身不形成业务事实。

不拥有：

- 主体主档。
- 业务域申请、订单、住宿单、维修单、运行任务。
- 财务事实。
- 管理结论。

## 2. 共享治理层

职责：

- 主体、车辆、关系、身份解析。
- 重复识别、合并建议、差异提示。
- 跨域对象索引、共享状态、风险回执。
- 输出 `SubjectResolution` 和主对象关系引用。
- 只读消费 `BusinessSummaryReadModel`，用于对象画像和关系图。

不拥有：

- 业务域源事件。
- 正式财务事实。
- 经营统计结论。
- 管理拍板处理动作。

## 3. 业务域事实层

职责：

- 各业务域拥有自己的申请、事件、状态、资源、业务摘要和金额依据。
- 业务域通过 `DomainIntake` 接入来源和主对象。
- 业务域可以输出 `BusinessSummaryReadModel` 给搜索、共享治理、驾驶舱和分析。

不拥有：

- 其它域事实。
- 正式财务真值。
- 全局主对象去重。
- 管理分析结论。

## 4. 财务真值层

职责：

- 合同、收款、付款、押金、费用、工资、报销、退款、扣减、核销和核算。
- 承接业务域金额依据。
- 输出财务结果摘要和财务状态回执。

不拥有：

- 业务域源事件。
- 主体/车辆主档。
- 业务异常关闭动作。

## 5. 执行层

职责：

- 通过 `VNextExecutionItem`/WorkItem 收口所有可写动作。
- 收集当前步骤输入、固定选择、证据、财务边界和提交确认。
- 产生事件、关系事实、财务事实、`ManagementDecisionRecord` 或修正记录。

不拥有：

- 业务事实本身的最终归属。
- 读模型解释权。
- 页面私有写入路径。

## 6. 读模型与分析层

职责：

- 搜索、列表、详情摘要、Projection、Lens、管理驾驶舱、统计分析。
- 只读消费各域 `BusinessSummaryReadModel` 和投影。
- 支持查看、筛选、钻取、报警、趋势和拍板入口。

`BusinessSummaryReadModel` 必须包含：

- `sourceDomain`：摘要来源域。
- `sourceObjectType` 和 `sourceObjectRef`：可追溯源对象。
- `summaryGrain`：来源、主体、车辆、业务对象、财务对象、管理记录等粒度。
- `displayFields`：用户可见摘要字段，按 `VNextLanguageContract` 渲染。
- `status`、`risk`、`amountSummary`、`evidenceSummary`：可选但必须标明来源。
- `legalActions`：只允许跳转到办理项、详情或拍板入口。
- `forbiddenActions`：明确不能原地编辑、不能处理异常、不能写财务事实。
- `freshness`：更新时间、同步状态和过期提示。
- `auditRef`：来源域和生成链路。

不拥有：

- 任何源域事实。
- 财务真值。
- 异常处理事实。
- 原地编辑能力。

## 7. 体验层

职责：

- 移动端一级入口：今日、工作项、搜索、我的。
- PC 辅助面：财务、治理、管理分析。
- 页面阅读顺序、按钮、状态、错误、空态和语言表达。
- 按 `VNextLanguageContract` 渲染中文、俄语、吉语。

不拥有：

- 事实归属。
- 权限最终判断。
- runtime 写入规则。
- 翻译兜底规则的私有解释权。

## 读写边界

| 层 | 可写 | 只读 |
| --- | --- | --- |
| 来源归因 | 来源记录 | 主体候选、业务接入状态 |
| 共享治理 | 主对象、关系、状态回执 | 各域摘要、财务结果摘要 |
| 业务域事实 | 本域申请、事件、状态、金额依据 | 来源、主对象、财务摘要 |
| 财务真值 | 财务事实、核销、核算 | 业务金额依据、主对象 |
| 执行层 | 办理项提交结果 | 上下文、阻断、摘要 |
| 读模型与分析 | 视图配置、拍板入口记录 | 各域摘要、投影 |
| 体验层 | 无源事实写入 | 所有可见上下文 |
| 三语言合同 | 语言资源、显示键、fallback 规则 | 稳定 value、源域摘要、页面结构 |

## 跨层规则

- 下层事实不能被上层读模型改写。
- 来源只能转接入，不能直接转业务事实。
- `DomainIntake` 只能代表业务接入，不能提前定真业务事件。
- 共享治理只能合并主对象和关系，不能合并业务事件。
- 财务结果只能摘要回写，不能被业务域改写。
- 分析结论只能触发办理项或 `ManagementDecisionRecord`，不能直接处理异常。
- 用户可见语言必须来自 `VNextLanguageContract`，不能把 enum/status/action value 直接展示给用户。
