# 可复用体验模式

## 设计锚点

本文件遵循七层模型和 `VNextLanguageContract`。体验模式只能渲染和路由，不得发明事实；任何写入必须进入办理项/WorkItem 和提交确认。

## 来源卡

用于展示 `SourceAttribution`。

必须显示：

- 来源类型
- 渠道和触点
- 原始诉求
- 接入时间和接入人
- 候选业务域
- 当前状态
- 初始证据

可用动作：

- 继续解析主体
- 转业务域接入
- 标记重复
- 关闭无效来源

不得直接生成业务事实。所有标题、状态、动作和错误必须三语言可读。

## 主体解析卡

用于 `SubjectResolution`。

必须显示：

- 候选主体或车辆
- 匹配依据
- 差异字段
- 重复风险
- 合并建议
- 不可合并原因

可用动作：

- 选择已有主体
- 创建新主体
- 发起关系修正
- 标记待复核

不得合并业务域事件或财务事实。

## 转域确认卡

用于把来源转为 `DomainIntake`。

必须显示：

- 来源摘要
- 主对象解析状态
- 目标业务域
- 接入条件
- 所需证据
- 转入后将创建的办理项
- 失败路由

不得把来源直接变成业务事实。

## 办理项卡

用于 `VNextExecutionItem`。

必须显示：

- `primaryBusinessObject`
- `requiredReadContext`
- `editableInputs`
- `fixedSelections`
- `evidenceRequirements`
- `financialContext`
- `legalActions`
- `blockingReasons`
- `handoffSummary`

流程动作不得进入字段；用户输入不得包含系统已能带出的只读上下文。

## 对象摘要块

必须显示：

- 业务锚点
- 对象类型
- 当前状态
- 关键关系
- 风险或阻断
- 可钻取对象

不得显示内部 ID、payload hash、definitionId、commandSubmissionId 作为主信息。

## 上游只读摘要

必须显示：

- 来源对象
- 上游确认状态
- 已带出字段
- 不可编辑原因
- 缺失时下一步

不得要求用户重复录入已确认上游事实。

## BusinessSummaryReadModel 卡

用于搜索、详情、共享治理画像、管理驾驶舱和分析。

必须显示：

- 摘要来源域
- 来源对象类型和业务锚点
- 摘要粒度
- 用户可读状态
- 关键金额或证据摘要
- 更新时间和同步状态
- 可钻取对象
- 合法动作入口

不得：

- 原地编辑源域事实。
- 原地处理异常。
- 把分析结果写回成业务事实。
- 隐藏摘要来源域。

## 当前输入区

必须区分：

- 真实输入
- 固定选择
- 系统预览
- 只读摘要
- 后台默认值

流程动作不得进入字段。固定范围字段必须使用下拉、单选、分段按钮或对象选择器，不得退化为手填。

## 证据块

必须显示：

- 证据名称
- 是否必需
- 当前状态
- 绑定入口
- 拒绝、错绑、过期或上传失败原因
- 下一步处理方式

证据名称不得显示哈希、内部码或旧业务词。证据名称、状态和错误必须三语言可读。

## 财务边界块

必须显示：

- 金额
- 币种
- 业务对象
- 收付方向
- 阶段语义：依据、申请、承接中、已定真、已核销、已核算
- 应收/应退、已收/已退、本次金额、差额
- 财务承接状态

业务域页面不得确认正式财务事实。

## ManagementDecisionRecord 卡

用于管理拍板。

必须显示：

- 只读经营摘要
- 拍板依据和时间范围
- 拍板人和责任角色
- 后续责任域
- 必须生成或打开的办理项
- 禁止效果：不能直接关闭异常、不能写财务事实、不能改业务事件

不得把拍板卡做成异常处理页面。

## 三语言护栏

所有可复用模式必须声明：

- 标题 key
- 状态 key
- 主按钮 key
- 错误 key
- 空态 key
- 长文案策略

三语言长文案不得遮挡主按钮、金额、证据状态、下一步承接区。

## 下一步承接区

必须显示：

- 下一办理项
- 下一责任角色
- 等待回执
- 阻断原因
- 已完成只读记录
- 投影同步中状态

提交后不得只显示“成功”。
