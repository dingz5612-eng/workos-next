# 宿舍财务边界与跨域移交

## 设计锚点

本文件遵循总设计七层模型，定义宿舍经营域与合同财务域的边界。宿舍域通过 `DomainIntake` 接入金额诉求，通过 `VNextExecutionItem` 输出金额依据，通过 `BusinessSummaryReadModel` 只读消费财务回执，三语言表达遵循 `VNextLanguageContract`。正式财务真值只归合同与财务域；本文件不修改当前 OAM、generated、runtime、surface 或 tests。

金额字段、币种、收付方向、阶段语义和财务承接状态必须遵循 `09-scenario-step-field-contracts.md`；金额依据的状态转移必须遵循 `08-state-action-transition-contract.md`。财务域可以接收、处理中、确认、驳回；宿舍域只能据此更新只读摘要或发起修正办理项。

## 宿舍可形成的金额依据

| 依据 | 宿舍可写 | 财务承接后形成 |
| --- | --- | --- |
| 住宿费用依据 | 价格快照、周期、床位、折扣依据、业务对象 | 应收、收款、核销 |
| 押金申请 | 押金金额、币种、收付方向、住宿单、证据 | 押金财务事实 |
| 续住费用依据 | 续住周期、价格差额、应收依据 | 收款或应收调整 |
| 换房差额依据 | 原床位、目标床位、差额说明 | 收款、退款或调整 |
| 退住扣减依据 | 检查结果、损耗、超期、服务费 | 扣减事实 |
| 退款依据 | 应退金额、币种、退款原因、业务对象 | 退款事实 |
| 内部结算依据 | 员工住宿、内部承担方、周期 | 内部结算或工资/报销承接 |

宿舍金额依据不是正式财务事实。

## 财务承接包

宿舍移交财务必须包含：

- 来源业务对象：住宿申请、住宿单、续住、换房、退住结算。
- 主体摘要：住客、企业、员工或付款方。
- 金额。
- 币种。
- 收付方向。
- 阶段语义：依据、申请、承接中、已定真、已核销、已核算。
- 业务对象和日期范围。
- 证据状态。
- 当前不可处理原因。
- 下一办理项。
- 三语言提示 key。

缺少金额、币种、业务对象或收付方向时，不得进入财务承接。

## 财务接收与驳回合同

| 财务处理结果 | 宿舍可做 | 宿舍禁止 | 下一步 |
| --- | --- | --- | --- |
| `finance_accepted_for_processing` | 显示承接中摘要 | 显示已收/已退/已核销 | 等待财务结果摘要 |
| `finance_confirmed_readonly` | 只读展示财务回执 | 复制财务事实为宿舍事实 | 进入入住、续住、关闭或只读记录 |
| `finance_rejected` | 展示驳回原因并打开修正办理项 | 原地改财务事实或隐藏驳回 | 回宿舍金额依据修正 |
| `finance_requires_more_evidence` | 打开证据补交办理项 | 跳过证据继续提交 | 补证后重新提交财务承接 |
| `finance_not_applicable` | 记录无需财务原因 | 用无需财务替代金额依据 | 继续宿舍流程并保留审计 |

财务驳回原因必须是稳定 value，并通过中文、俄语、吉语 label 展示。驳回后的修正字段必须来自 `09` 的 `editableInputs` 和 `evidenceMaterials`，不得由财务摘要页面临时发明。

## 押金承接

```text
住宿单
-> 押金申请
-> 财务承接办理项
-> 押金财务事实
-> 财务结果摘要
-> 宿舍只读消费
```

边界：

- 宿舍可以申请押金。
- 宿舍可以展示押金承接状态。
- 宿舍不能确认已收押金。
- 押金余额、冻结、扣减、退还以财务结果摘要为准。

## 收款承接

```text
住宿费用依据
-> 财务收款办理项
-> 收款事实
-> 核销/核算
-> 财务结果摘要
-> 宿舍只读消费
```

宿舍页面应显示“等待财务”“财务已确认摘要”“财务驳回原因”，不得显示宿舍域自造的收款结论。

## 退款/扣减承接

```text
退住检查
-> 退款/扣减依据
-> 财务承接办理项
-> 退款/扣减事实
-> 财务结果摘要
-> 关闭住宿单或追加修正
```

阻断：

- 房间床位检查未完成。
- 维修/清洁责任未明。
- 缺少币种、金额、业务对象或证据。

## 内部员工住宿承接

内部员工住宿可能进入：

- 财务支付/扣减。
- 工资依据。
- 内部结算。
- 无财务承接的内部回执。

具体路径由人事行政和合同财务域的权威决定。宿舍只能输出住宿事实和金额/结算依据。

## 财务回执摘要

财务回执以 `BusinessSummaryReadModel` 只读返回宿舍：

- `financeStatus`
- `amount`
- `currency`
- `direction`
- `financeObjectRef`
- `confirmedAt`
- `rejectedReason`
- `nextFinanceAction`
- `auditRef`

宿舍不得复制财务事实字段到宿舍事实表，只能引用摘要。

## 三语言财务表达

必须三语言可读：

- 金额、币种。
- 收款、付款、押金、退款、扣减。
- 应收/应退、已收/已退、本次金额、差额。
- 财务承接中、已确认、已驳回、需修正。
- 驳回原因和下一步。
