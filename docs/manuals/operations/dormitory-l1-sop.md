# Dormitory L1 SOP

## 范围

本 SOP 只适用于当前 Dormitory L1 内测观察。

- Dormitory remains L1 Internal Pilot Observation only。
- Dormitory L2 Production = false。
- Business Production = blocked。
- Repair / Parts / HR = L0 Contract Preview。
- Day-2 not started。

本 SOP 不授予 Dormitory L2 Production，不授予 Business Production。

## 每日观察

1. 查看 Today Mission Control 和 Work queue。
2. 检查 blocked、missing evidence、waiting finance、projection pending。
3. 记录 P0 / P1 / P2。
4. 对 403 / 409 / 422 按用户手册处理。
5. 运行 observation sequence gate 时确认 Day-2 artifact 未创建。

## 证据

证据必须区分需求、草稿、真实附件、可信校验、拒绝和作用域不匹配。缺证据不能确认。

## 账务

押金进入 liability。普通收款不得进入 deposit liability。退款不得超过原 liability。Correction 必须 append reversal / compensation。

## 升级

P0 停止推进并修复。P1 进入 hold 或升级 owner。P2 记录为后续优化。

## 不允许

不进入 Day-2，不声明 production，不扩业务线，不绕过 Operations Runtime。
